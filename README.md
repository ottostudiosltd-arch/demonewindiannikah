# IndiaNikah — Modern Redesign & Halal Matrimony Experience

100% Free (Non-Profit) Indian Muslim Matrimony frontend redesigned with modern UI/UX, keeping the authentic Islamic spirit, modesty, and family involvement at its core.

## 🚀 Live Demo on GitHub Pages
👉 **[https://ottostudiosltd-arch.github.io/demonewindiannikah/](https://ottostudiosltd-arch.github.io/demonewindiannikah/)**

---

## ✨ Key Features
- **Clean & Focused Home Screen**: Islamic arch hero card, 3 trust pillars (Verified, Family, Safe), and quick search launcher.
- **Search Options Bottom Sheet**: Quick Search, Advanced Search, and instant Recent Searches recall.
- **Dedicated New Profiles Page**: Uniform non-overlapping responsive card grid (2-column on mobile, 4-column on desktop), verified badges, filter chips, and filter modal.
- **Comprehensive Profile Hub**:
  1. Profile Overview (Tausif, 23, Verified, views, favorites, proposals counters)
  2. Edit Profile (10 structured sections)
  3. My Photos (Photo management & privacy guidelines)
  4. Profile Completion (80% progress ring & checklist)
  5. Privacy & Settings (Visibility controls, contact toggles)
  6. Profile Menu (Quick shortcuts)
- **Proposals & Connections**:
  - `Received (1)` proposals
  - `Sent (2)` proposals
  - `Secure Chat` direct encrypted halal messaging
- **Responsive Layout**:
  - Full desktop navigation and footer on PC/tablets
  - Clean minimal footer and native bottom nav bar on mobile devices

---

## 💻 Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS (Custom blush & rose palette: `#FFF9FA`, `#9B1B47`)
- **Icons**: Lucide React
- **Hosting**: GitHub Pages via GitHub Actions
